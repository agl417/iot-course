# 物联网课程

课程资料与代码仓库。近期天气数据用于物联网数据读取、清洗与展示练习。

## 合川区天气数据

数据文件：[`data/weather/hechuan_2026-11-15_to_19.csv`](data/weather/hechuan_2026-11-15_to_19.csv)

范围：2026-11-15 至 2026-11-19。11 月 15–18 日为历史日记录；11 月 19 日为带时间戳的部分观测快照（当天尚未结束），不可作为完整日最高/最低温统计。来源间观测时间和数值会有差异，CSV 保留各来源的时间戳和链接。

来源：
- [天气后报：合川历史天气](https://www.tianqihoubao.com/weather/top/hechuan.html)
- [中国气象局国家气象中心：合川天气预报/实况](https://www.nmc.cn/publish/forecast/ACQ/hechuan.html)
- [和风天气：合川区天气](https://www.qweather.com/weather/hechuan-101040300.html)
